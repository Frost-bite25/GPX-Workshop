# GPX Workshop versions

Bump `VERSION` in build.py with every change to the core app, and add a line here.

- **Version 14.11** (22 Nov 2026): undo 14.10's stretch — on iPad the strip below is outside the area iOS lets the app draw in, and stretching cut off the bottom buttons.
- **Version 14.10** (22 Nov 2026): installed app on iPad: fills to the bottom edge — works around iOS reporting the window shorter than the screen by the status-bar height.
- **Version 14.9** (22 Nov 2026): duplicates — Show them lists every repeated track with each copy's folder, which copy is kept (choose another with Keep this), tap a copy to see it on the map, and remove copies per track or all at once.
- **Version 14.8** (22 Nov 2026): installed app: undo 14.5's extra top gap and over-tall layout (bottom was cut off on iPad).
- **Version 14.7** (22 Nov 2026): duplicate clean-up — the library spots tracks that are in it more than once with exactly the same points and offers Remove duplicates (keeps one of each, extras go to Recently deleted). Restore no longer makes a second copy of a track that is already back in the library.
- **Version 14.6** (22 Nov 2026): SYNC FIX — a device closed during its first download could wrongly delete tracks from GitHub (and other devices then moved them to Recently deleted). Sync now waits until each track is saved on the device, only deletes from GitHub what is in that device's Recently deleted, only moves a track to Recently deleted when GitHub's Recently deleted shows it, and never acts on an incomplete listing. New: Restore deleted today.
- **Version 14.5** (22 Nov 2026): installed app: header buttons moved fully below iOS 26's top blur; app stretches to the bottom even when iOS reports a short viewport; screen measurements under Maps → App for diagnosing.
- **Version 14.4** (22 Nov 2026): installed app on iPad/iPhone: always fills the whole screen (no black strip at the bottom); status bar takes the header colour so iOS's top blur blends in; with no track selected the profile is one line on every screen size.
- **Version 14.3** (22 Nov 2026): waypoint labels no longer pile up — labels that would overlap shrink to small pins (name on hover or tap) and come back as you zoom in; the selected track's labels win.
- **Version 14.2** (22 Nov 2026): installed iPhone app: header runs behind the status bar and the buttons sit below iOS 26's blur band, so the top bar is sharp. Re-add the app to the home screen once to pick this up.
- **Version 14.1** (22 Nov 2026): phones: with no track selected, the profile shrinks to one line instead of leaving an empty graph area; the hint text wraps.
- **Version 14** (22 Nov 2026): installable app — home-screen icon, full screen, opens with no signal (app and lock screen kept on the device); Install button under Maps; Android: share GPX files from other apps straight into GPX Workshop. Fix: a start-up line switched off in 13 is back on.
- **Version 13** (22 Nov 2026): calmer, compact library text; on a computer a track's buttons show when you point at it; folders and tracks always A–Z (Day 2 before Day 10) with Unfiled at the top; every folder starts closed and only opens when you open it.
- **Version 12.1** (22 Nov 2026): shared links can hide the elevation graph (Hide/Show graph button next to the stats, remembered per link); new share option to start links with the graph hidden.
- **Version 12** (22 Nov 2026): shared links can be saved for offline — the page, the track and the satellite or Esri topo map along the route are kept on the phone, so the link opens with no signal. Needs the new sw.js file next to index.html.
- **Version 11.2** (13 Nov 2026): shared links decluttered on phones — one-row header, map type and contours behind a Map button, track list folds into a small button showing the active track, compact stats and chart, short footer note, no zoom buttons. Computer view unchanged.
- **Version 11.1** (13 Nov 2026): Send to Garmin on phones now saves the GPX file with step-by-step help to open it in Garmin Connect (the share sheet doesn't list Garmin Connect on every phone); shared links get a Send to Garmin button too (when downloads are allowed).
- **Version 11** (13 Nov 2026): Send to Garmin Connect (Export menu) — on a phone or iPad the full GPX goes to the share sheet for the Garmin Connect app; on a computer it downloads and opens Garmin Connect Courses for Import; tracks with several segments are flagged with a Split first button.
- **Version 10.2** (13 Nov 2026): folder text toned down — main folders slightly larger and semi-bold, sub-folders regular weight.
- **Version 10.1** (13 Nov 2026): main (top-level) folder names larger and bolder so they stand out from sub-folders.
- **Version 10** (13 Nov 2026): Garmin-friendly segments — GPX files with several segments are split into separate tracks kept together in a folder named after the file (Garmin Connect only loads the first segment); folders inside folders (drag a folder onto another, new folder inside, rename and remove move contents up a level); one-tap "Split into folders" for tracks already in the library; setting under Maps → Importing to keep segments instead.
- **Version 9.1** (13 Nov 2026): clicking a track on the map (2D or 3D) highlights it in the library — opens its folder, scrolls to it and flashes it; stronger highlight for the selected track.
- **Version 9** (13 Nov 2026): phone layout — compact two-row header with full-width search, tools as a swipeable bottom toolbar, panels slide up from the bottom, library drawer closes when you tap the map, bigger touch targets, no zoom-in on text boxes. PC and iPad unchanged.
- **Version 8.1** (12 Nov 2026): tool rail shows the name under each icon again.
- **Version 8** (12 Nov 2026): 3D view with terrain (satellite or topo, height exaggeration, fly along the track); Export menu with GPX, KMZ and KML for Google Earth; fix: segments taken out one at a time are all named "Track – Segment N", including the last one left.
- **Version 7** (12 Nov 2026): guest mode ("Use as a guest" on the lock screen when allowed; separate on-device library; no cloud or links; Export all; Exit guest mode asks for the password again); owner switch to allow guests and "Hand this device to a guest"; profile bar keeps distance, elevation and points when minimised, with totals when several tracks are selected.
- **Version 6.1** (12 Nov 2026): segments drop-down under each track in the library (pick, zoom, make its own track, delete; the picked segment is outlined yellow on the map); easier-to-read font (Atkinson Hyperlegible Next) in the app and shared pages.
- **Version 6** (12 Nov 2026): share links (secret GitHub Gist) with an end date (1, 7, 30, 90 days or none), Stop sharing, optional GPX download, expired links deleted automatically; slimmer icon-only tool bar; tabs on the map edges hide or show the library and the profile.

- **Version 1** (11 Nov 2026): editor and tools, base maps, library, Recently deleted (90 days), cloud sync to GitHub, password login.
