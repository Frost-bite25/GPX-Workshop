# GPX Workshop versions

Bump `VERSION` in build.py with every change to the core app, and add a line here.

- **Version 9** (13 Nov 2026): phone layout — compact two-row header with full-width search, tools as a swipeable bottom toolbar, panels slide up from the bottom, library drawer closes when you tap the map, bigger touch targets, no zoom-in on text boxes. PC and iPad unchanged.
- **Version 8.1** (12 Nov 2026): tool rail shows the name under each icon again.
- **Version 8** (12 Nov 2026): 3D view with terrain (satellite or topo, height exaggeration, fly along the track); Export menu with GPX, KMZ and KML for Google Earth; fix: segments taken out one at a time are all named "Track – Segment N", including the last one left.
- **Version 7** (12 Nov 2026): guest mode ("Use as a guest" on the lock screen when allowed; separate on-device library; no cloud or links; Export all; Exit guest mode asks for the password again); owner switch to allow guests and "Hand this device to a guest"; profile bar keeps distance, elevation and points when minimised, with totals when several tracks are selected.
- **Version 6.1** (12 Nov 2026): segments drop-down under each track in the library (pick, zoom, make its own track, delete; the picked segment is outlined yellow on the map); easier-to-read font (Atkinson Hyperlegible Next) in the app and shared pages.
- **Version 6** (12 Nov 2026): share links (secret GitHub Gist) with an end date (1, 7, 30, 90 days or none), Stop sharing, optional GPX download, expired links deleted automatically; slimmer icon-only tool bar; tabs on the map edges hide or show the library and the profile.
- **Version 5** (12 Nov 2026): Share page — saves the selected tracks as one web page anyone can open (map with base maps and contours, tracks, waypoints, elevation profile, stats, Download GPX).
- **Version 4** (12 Nov 2026): several logins on one site. Each person signs in with their own password and gets their own private tracks repository. Add and remove logins in the Cloud sync panel. Older single-login files still work.
- **Version 3** (12 Nov 2026): lock screen (password before the app opens), map keys for Thunderforest, Tracestrack, MapTiler, Mapy.com and Carto, Humanitarian map, your own layers as overlays, map keys / own layers / folders sync to other devices. Fix: in Draw, clicking on top of another track now adds a point instead of switching tracks.
- **Version 2** (12 Nov 2026): folders (create, move, rename, collapse, drag and drop), quick track rename, black theme, version label.
- **Version 1** (11 Nov 2026): editor and tools, base maps, library, Recently deleted (90 days), cloud sync to GitHub, password login.
